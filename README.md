## О проекте

«Оно тебе надо» — одностраничный лендинг аукциона вещей, в которые никто не верил.  
Проект выполнен в рамках 1-го спринта курса по фронтенд-разработке Яндекс Практикума.

Цель — отработать семантическую вёрстку, работу с типографикой и сетками (Flexbox, CSS Grid), привести макет из Figma к pixel-perfect реализации в браузере.

## Что реализовано на странице

- **Хедер** с логотипом, навигацией и контактами.
- **Промо-секция** с крупным заголовком и кнопкой «Сделать ставку».
- **Секция «Лоты»**:
  - карточки лотов (фильм, книга, картина) с фоном-изображением;
  - заголовок и описание каждого лота.
- **Секция «Об аукционе»** с текстовым описанием проекта и выделенными цитатами.
- **Футер** с адресом, контактами и навигацией.

## Мой вклад в проект

Репозиторий основан на учебном шаблоне Яндекс Практикума [`yandex-praktikum/ono-tebe-nado`](https://github.com/yandex-praktikum/ono-tebe-nado), но разметка и стили страницы реализованы мной.

В рамках проекта я:

- Сверстала страницу по макету из Figma c ориентацией на pixel-perfect.
- Построила сетки с помощью **Flexbox** и **CSS Grid**.
- Настроила типографику: подключила кастомные шрифты, задала иерархию заголовков и текстов.
- Использовала **семантическую HTML-разметку** (header, main, section, footer, nav).
- Организовала стили в отдельных файлах в папке `styles/`:
  - базовые стили и нормализация;
  - стили для блоков (по БЭМ-подходу);
  - переиспользуемые утилиты (классы для выравнивания, отступов и т.п.).
- Настроила простую структуру проекта: шрифты в `fonts/`, изображения в `images/`, стили в `styles/`.

## Технологии и подходы

- **HTML5** — семантическая разметка, корректная структура заголовков.
- **CSS3**:
  - Flexbox и CSS Grid для построения сеток;
  - позиционирование элементов (relative/absolute/fixed);
  - фоновые изображения и наложение текста на изображения;
  - стилизация ссылок и состояний по наведению.
- **Работа с макетом в Figma** — перенос шрифтов, отступов, размеров, цветов.
- **Git / GitHub** — базовый рабочий процесс с коммитами и веткой `main`.

## Структура проекта

- `index.html` — вся разметка страницы.
- `styles/global.css` — базовые стили, шрифты, цвета.
- `styles/style.css` — стили основных блоков страницы (хедер, лоты, об аукционе, футер).
